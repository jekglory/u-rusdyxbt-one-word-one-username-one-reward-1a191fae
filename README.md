One Word, One Username, One Reward — the entry is our own make.fun
username, and nothing else:

> gentle-owl-26

One word, no explanation, no links, no pitch. A judge model reads
two usernames at a time and picks the one that feels funnier or more
interesting. Gentle owl, twenty-six: soft, wise, and oddly specific
— the kind of handle that sounds like it already has a story.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python 3.13 standard library, no third-party packages)
writes the username to `/output/entry.txt` — exactly 1 word, 13
characters, byte-identical on every run.
